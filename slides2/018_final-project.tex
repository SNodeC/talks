\begin{frame}{Techniques to use}
  \begin{itemize}
    \item Master-Branch of SNode.C
    \item Express-Module of SNode.C
    \item MariaDB as external database
    \item MariaDB-Module of SNode.C (have a look at the {\tt apps/database/testmariadb.cpp} application how to use this module)
    \begin{itemize}
      \item Install {\tt libmariadb-dev} using {\tt apt install libmariadb-dev} as {\tt root}
      \item Install {\tt mariadb-server} using {\tt apt install mariadb-server} as {\tt root}
    \end{itemize}
    \item Cookies for session management
    \item URL-Queries to select a specific suptopic and thread. (For reading and posting)
    \item {\tt app.post(\ldots)} for posting to a thread.
    \item Development of a database model that supports the desired functionalities.
  \end{itemize}
\end{frame}
