\begin{frame}{Basic Functionalities -- what should work?}
  \alert{Basic (mandatory) functionalities}
  \begin{itemize}
    \item Users should be able to register itself by providing a username and password.
    \item Users should be able to create a new subtopic.
    \item Users should be able to create new threads in a subtopic.
    \item Users should be able to post topics to a thread.
    \item Users should be able to read all posts of a thread.
  \end{itemize}
  \alert{Additional (optional) functionalities}
  \begin{itemize}
    \item This functionalities should be implemented without additional security considerations.
    \item It is up to you to provide additional functionalities if neccessary.
  \end{itemize}
\end{frame}
