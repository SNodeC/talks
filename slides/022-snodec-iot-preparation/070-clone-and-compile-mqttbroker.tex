\section{Clone, Build, and Install the SNode.C Application MQTT-Broker}

\begin{frame}{Clone, Build, and Install the SNode.C Application MQTT-Broker}
  \begin{enumerate}
    \item Under the directory \lstinline|projects| create a directory named \lstinline|mqttbroker|,
    \item change to that directory.
    \item Clone the MQTT-Broker application from \textcolor{fh-ooe-red}{\href{https://github.com/VolkerChristian/mqttbroker}{https://github.com/VolkerChristian/mqttbroker}} using \textcolor{fh-ooe-red}{HTTPS} as clone-method.
    \item Import the MQTT-Broker project into QT-Creator.
    \item Build and install MQTTBroker.
    \item Start the \texttt{\textcolor{fh-ooe-red}{mqttbroker}} and the \texttt{\textcolor{fh-ooe-red}{mqttintegrator}} applications separat in two different terminal windows.
    \item Watch the output of both applications.
    \item Use \texttt{\textcolor{fh-ooe-red}{mosquitto\textunderscore{}sub}} and  \texttt{\textcolor{fh-ooe-red}{mosquitto\textunderscore{}pub}} connected to the \texttt{\textcolor{fh-ooe-red}{mqttbroker}}.
    \item Try to find out what is going on in behind by interpreting the output.
  \end{enumerate}
\end{frame}
