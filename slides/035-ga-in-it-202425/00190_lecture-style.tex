\section[nosectionpage]{Style of Lecture}

\begin{frame}{IoT in Hagenberg: \alert{Style of Lecture}}
The vision of designing and building concrete LoRaWAN gateways, LoRaWAN nodes and web applications has a major implication on the lecture style:
\begin{itemize}
    \item It will \alert{not be a classical lecture} but more of a \alert{workshop}.
    \item I will \alert{not lecture a lot}, but sometimes i will.
\end{itemize}
\begin{description}[You Will]
    \item [I will]
    \begin{itemize}
        \item be \alert{your coach} during the lecture/workshop.
        \item advise on technologies in general.
        \item advise on hardware and software to let the idea come true, and here especially on
        \begin{itemize}
            \item ESP-8266, ESP-32, sensors, actuators, bus systems, Raspberry Pi,
            \item MQTT and the MQTTSuite and
            \item SNode.C/express and Node.js/express for web development.
        \end{itemize}
        \item \ldots
    \end{itemize}
    \item[You will]
    \begin{itemize}
        \item do \alert{research about topics} related, relevant and necessary \alert{for the project}.
        \item \alert{design and build the hardware} for the LoRaWAN nodes.
        \item \alert{develop the protocol} used to transmit the measurements to \alert{The Things Network}.
        \item \alert{implement the software} for the nodes.
        \item \alert{design and implement the web application} used to administrate the gateways and nodes.
        \item \alert{design and implement the frontend web application} for \alert{data access} and \alert{data analysis}.
        \item \ldots
    \end{itemize}
\end{description}
\end{frame}
