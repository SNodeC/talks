\begin{frame}{SunCharge -- Prototype Scope \& Required Resources}
\small
\begin{columns}[T,onlytextwidth]
    \begin{column}{0.52\textwidth}
        \textbf{Hardware}
        \begin{itemize}
            \item Small photovoltaic module, approximately 20--50\,W class
            \item Solar charge controller / MPPT module
            \item Low-voltage LiFePO$_4$ battery with BMS
            \item ESP32-class controller with LoRaWAN
            \item Voltage/current/energy measurement
            \item DC/DC conversion and low-voltage charging interfaces
            \item USB/USB-C or representative dummy loads
            \item Load switches and electrical protection/fuses
        \end{itemize}
    \end{column}
    \begin{column}{0.48\textwidth}
        \textbf{Software \& Infrastructure}
        \begin{itemize}
            \item LoRaWAN gateway and The Things Network
            \item MQTT / MQTTSuite backend
            \item Database for energy flows and charging sessions
            \item Charging/control logic
            \item Web dashboard
        \end{itemize}
    \end{column}
\end{columns}

\begin{block}{Final Demonstration}
The charging station autonomously reacts to changing solar production, battery state and charging demand.
\end{block}
\end{frame}
