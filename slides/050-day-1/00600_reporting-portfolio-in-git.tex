\section{Reporting/Portfolio in Git-Repository}

\begin{frame}{Reporting/Portfolio in Git-Repository}
\begin{itemize}
\item Pick one repository/file/folder of pair to report lab work
\begin{itemize}
\item Give mutual access from both personal repos
\item Everything goes in there
\begin{itemize}
\item Everybody needs one portfolio main document – link shared work into it
\item All from lab challenges (and also content that spills into homework)
\item If you work in pair, work on one shared document (link into a personal main portfolio document) –- same for group
\end{itemize}
\item Text and documentation in Git repo as Restructured Text or Markdown (no Microsoft Word/Libreoffice files for documentation – exception tables can be done as pdf or google sheet link but preferred in markup)
\item Code goes into one shared git repo (needs to be linked in portfolio) -- reasonable git etiquette (no binaries but pictures you took or drew) -- take pictures!
\end{itemize}
\end{itemize}
\end{frame}
