\section{Learning Objectives}

\begin{frame}{Learning Objectives}
\begin{itemize}
\item Define and critically reflect on the term “Internet of Things” as well as align and position Internet Of Things technology in comparison to cloud and mobile computing
\item Equip most physical objects with networked sensors
\item Equip and interact with most physical objects with actors
\item Write code to set-up systems to collect, visualize, analyze, and act on data from the physical world
\item Design and implement various IoT systems made up of sensors, wireless network connection, and actuators
\item Build and test a complete working IoT system as well as design and implement respective simulator components to speed up testing
\item Present and defend the design and implementation of several Internet Of Things Systems in a portfolio and public presentations
\end{itemize}
\end{frame}
