\section[nosectionpage]{The \texttt{SocketContextFactory} and the \texttt{SocketContext} of the MQTT-Broker}

\begin{frame}[fragile]{The \texttt{SocketContextFactory} and the \texttt{SocketContext} of the MQTT-Broker}
  \begin{itemize}
    \item \alert{MQTT-Broker}'s \alert{\texttt{SocketContextFactory}} itself is designed as a \alert{template class} expecting a \alert{\texttt{std::string}} as \alert{non-type template argument} which has to contain a \alert{JSON} object.
    \begin{itemize}
      \item By \alert{providing} such a \alert{JSON} object the \alert{broker} would \alert{also} act as an \alert{integrator} which \alert{maps incoming topics and messages} to \alert{outgoing topics and messages controlled} by the \alert{mapping describtion in the JSON} object.
      \item If \alert{no JSON}-mapping (empty string) is provided, the broker acts as a \alert{pure broker}.
    \end{itemize}
    \item \alert{MQTT-Broker}'s \alert{\texttt{SocketContext}} is a class which \alert{inherits multible super classes}. Most \alert{important} it is \alert{derived from} the plain \alert{\texttt{iot::mqtt::server::SocketContext}} provided by SNode.C.
    \begin{itemize}
      \item The \alert{\texttt{iot::mqtt::server::SocketContext} already provides a full MQTT broker} implementation.
      \item By \alert{inheriting from this class} one has the \alert{opportunity} to \alert{override any method associated with incoming MQTT packets}, most \alert{important} the \alert{\texttt{onPublish}} method, \alert{associated} with an incoming \alert{MQTT publish packets}.

      \begin{cppcode}[gobble=8]
        void onPublish(iot::mqtt::packets::Publish& publish) override;
      \end{cppcode}
      \item This \alert{method is called for every incoming MQTT publish message}.
      \item The \alert{\texttt{iot::mqtt::packets::Publish}} argument passed to ths method \alert{contains the complete information of the publish message}.
    \end{itemize}
  \end{itemize}
\end{frame}
