\begin{frame}{IoT in Hagenberg: Workshop Responsibilities}{The Water-Monitoring Project as a Concrete Example}
\small
Building LoRaWAN gateways, sensor nodes and web applications calls for a workshop, with short lectures when needed.
\medskip
\begin{columns}[T,onlytextwidth]
\column{.47\textwidth}
\begin{block}{I Will: Coach and Advise}
\begin{itemize}
\item Coach your team and advise on technologies.
\item Help turn the idea into hardware and software.
\item Support ESP8266/ESP32, sensors, actuators, buses and Raspberry Pi.
\item Advise on MQTT and the MQTTSuite.
\item Support web development with SNode.C/express and Node.js/express.
\end{itemize}
\end{block}
\column{.49\textwidth}
\begin{block}{You Will: Research, Build and Integrate}
\begin{itemize}
\item Research what the project needs.
\item Design and build LoRaWAN-node hardware.
\item Define the measurement protocol for The Things Network.
\item Implement the node software.
\item Build web administration for gateways and nodes.
\item Build the frontend for data access and analysis.
\end{itemize}
\end{block}
\end{columns}
\end{frame}
