\begin{frame}{What Had to Come Together?}
\begin{itemize}
    \item Physical \textbf{sensors, electronics and power supply}
    \item Embedded software on distributed \textbf{ESP32-class nodes}
    \item \textbf{LoRaWAN} communication and gateways
    \item A defined data format and integration with \textbf{The Things Network}
    \item \textbf{MQTT}, backend services and persistent data
    \item A web interface for administration, access and analysis
    \item And finally: \textbf{integration and debugging across team boundaries}
\end{itemize}
\begin{alertblock}{A Real IoT System}
The difficult part is rarely one sensor or one program. The difficult part is making \textbf{everything work together}.
\end{alertblock}
\end{frame}
