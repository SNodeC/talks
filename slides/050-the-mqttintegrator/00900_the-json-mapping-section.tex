\subsection{The JSON Structure of a \texttt{json} Mapping Section}

\begin{frame}[fragile]{The JSON Structure of a \texttt{json} Mapping Section}
  The \textcolor{fh-ooe-red}{\texttt{json}} mapping section describes the \textcolor{fh-ooe-red}{mapped topic} and the \textcolor{fh-ooe-red}{message mapping} where the \textcolor{fh-ooe-red}{incoming message} is \textcolor{fh-ooe-red}{interpreted as a JSON object} of an \textcolor{fh-ooe-red}{\href{https://github.com/pantor/inja/tree/master}{inja template}}. The message \textcolor{fh-ooe-red}{JSON object} is available in the template in the variable \texttt{\textcolor{fh-ooe-red}{message}}\\E.g.:

  \begin{jsoncode}[gobble=4]
    {
        "json" : {
            "mapped_topic" : "test/onboard/set",
            "mapping_template" : "{{ message.time.start }} to {{ message.time.end + 1 }}pm",
            "retain" : false,
            "qos" : 0
        }
    }
  \end{jsoncode}
  This \texttt{\textcolor{fh-ooe-red}{mapping\_template}} renders the following JSON object as \texttt{\textcolor{fh-ooe-red}{17 to 20pm}}.

  \begin{jsoncode}[gobble=4]
    {
        "time" : {
            "start" : 17,
            "end" : 19
        }
    }
  \end{jsoncode}
  Have a look at the \textcolor{fh-ooe-red}{\href{https://github.com/pantor/inja/tree/master}{inja documentation}} for more details about templates.
\end{frame}
