\begin{itemize}
     \item The WS libraries are \alert{loaded dynamically} (\texttt{dlopen()}, \ldots) as \alert{plugins} during \texttt{HTTP-upgrade}.
     \item The requested subprotocol (e.g. \texttt{tiktaktoe}, \texttt{echo}, \texttt{mqtt}) is also \alert{dynamically loaded} as plugin.
     \item Both, WS libraries and subprotocol (SP) Libraries \alert{must obey a naming convention}.
     \item WS and SP libraries must provide \texttt{static} \alert{factory-factory} functions.
     \item Concrete SP libraries must be implemented by the user (abstract base class \texttt{SubProtocol).}
   \end{itemize}
\end{frame}
