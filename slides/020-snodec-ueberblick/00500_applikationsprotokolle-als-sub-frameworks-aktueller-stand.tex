\section{Application Protocols as Sub-Frameworks}

\begin{frame}{Application Protocols as Sub-Frameworks}{Current Status}
   \begin{description}[WebSocket (WS):]
     \item [HTTP/1.1:] Server and client side including virtual hosts support.
     \item [HTTP/Express:] Server-side API equivalent to Node.JS/Express
     \item [WebSocket (WS):] Server and client side
     \item [MQTT:] Server and client side (MQTT v3.1.1, v5.0 in planning)
     \item [MQTT via WS:] Server and client side (what MQTT can do, MQTT via WS can automatically do too)
   \end{description}
\end{frame}
