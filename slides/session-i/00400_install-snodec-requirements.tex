\section{Install all Necessary Development Tools for SNode.C}

\begin{frame}{Install all Necessary Development Tools for SNode.C}
  \begin{itemize}
    \item Learn how to install and update software packages using the tool \alert{\texttt{apt}} in Debian
    \item Install the following packages used for developing C++ application:
    \begin{itemize}
      \item \textcolor{fh-ooe-red}{\texttt{build-essential}} needed to compile code on Linux.
      \item \textcolor{fh-ooe-red}{\texttt{manpages-dev}} contains documentation about all std-library functions and classes.
      \item \textcolor{fh-ooe-red}{\texttt{git}} for version control.
      \item \textcolor{fh-ooe-red}{\texttt{cmake}} automates build process of applications and libraries.
      \item \textcolor{fh-ooe-red}{\texttt{ninja}} a a small build system with a focus on speed.
      \item \textcolor{fh-ooe-red}{\texttt{g++}} the C++ compiler from the \textcolor{fh-ooe-red}{G}NU \textcolor{fh-ooe-red}{C}ompiler \textcolor{fh-ooe-red}{C}ollection \textcolor{fh-ooe-red}{GCC}.
      \item \textcolor{fh-ooe-red}{\texttt{clang}} \textcolor{fh-ooe-red}{C} \textcolor{fh-ooe-red}{L}anguage \textcolor{fh-ooe-red}{F}amily \textcolor{fh-ooe-red}{F}rontend for the \textcolor{fh-ooe-red}{L}ow \textcolor{fh-ooe-red}{L}evel \textcolor{fh-ooe-red}{V}irtual \textcolor{fh-ooe-red}{M}achine \textcolor{fh-ooe-red}{LLVM} -- another compiler.
      \item \textcolor{fh-ooe-red}{\texttt{qtcreator}} a versatile \textcolor{fh-ooe-red}{I}ntegrated \textcolor{fh-ooe-red}{D}evelopment \textcolor{fh-ooe-red}{E}nvironment \textcolor{fh-ooe-red}{IDE}.
    \end{itemize}
    \item Install the following applications by downloading them from the Web.
    \begin{itemize}
      \item \textcolor{fh-ooe-red}{\texttt{SmartGit}} a free (for non-commercial use) versatile frontend for git. (See: \textcolor{fh-ooe-red}{\href{https://www.syntevo.com/}{https://www.syntevo.com/}})
    \end{itemize}
  \end{itemize}
\end{frame}
