\section{Example usage of SNode.C}

\begin{frame}{Example of using SNode.C}
   \begin{block}{Echo application}
   \begin{itemize}
   \item Imagine you want to create a simple TCP (stream)/IPv4 (in) server/client pair that ping-pong legacy plaintext data to each other.
   \item The client starts sending text data to the server, and the server reflects this data back to the client. The client receives this reflected data and sends it back to the server again. This data ping-pong is supposed to last forever.
   \end{itemize}
\end{block}
   \begin{description}
     \item [The user] must
     \begin{itemize}
       \item classes derived from \texttt{SocketContextFactory} and
       \item classes derived from \texttt{SocketContext}
     \end{itemize}
     provide for server and client.
     \item [SNode.C] represents "`ready to use"'
     \begin{itemize}
       \item \texttt{SocketServer} and
       \item \texttt{SocketClient}
     \end{itemize}
     Classes available for every network protocol.
   \end{description}
\end{frame}
