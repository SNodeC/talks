\part{Story Driven Modeling}

\begin{frame}{Story Driven Modeling}
\begin{itemize}
\item Scenarios first, very concrete, example based
\item Scenarios are base for tests (similar to tests first)
\item First diagrams usually on object level to show relations between concrete instances
\item Very agile, iterative development process
\item Allows and embraces problems and their solutions
\end{itemize}
\end{frame}
