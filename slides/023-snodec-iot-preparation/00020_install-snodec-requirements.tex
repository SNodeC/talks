\section{Install all Necessary Development Tools for SNode.C}
\withsectionpage

\begin{frame}{Install all Necessary Development Tools for SNode.C}
  \begin{itemize}
    \item Learn how to install and update software packages using the tool \alert{\texttt{apt}} in Debian
    \item Install the following packages used for developing C++ application:
    \begin{itemize}
      \item \alert{\texttt{build-essential}} needed to compile code on Linux.
      \item \alert{\texttt{manpages-dev}} contains documentation about all std-library functions and classes.
      \item \alert{\texttt{git}} for version control.
      \item \alert{\texttt{cmake}} automates build process of applications and libraries.
      \item \alert{\texttt{ninja}} a a small build system with a focus on speed.
      \item \alert{\texttt{g++}} the C++ compiler from the \alert{G}NU \alert{C}ompiler \alert{C}ollection \alert{GCC}.
      \item \alert{\texttt{clang}} \alert{C} \alert{L}anguage \alert{F}amily \alert{F}rontend for the \alert{L}ow \alert{L}evel \alert{V}irtual \alert{M}achine \alert{LLVM} -- another compiler.
      \item \alert{\texttt{qtcreator}} a versatile \alert{I}ntegrated \alert{D}evelopment \alert{E}nvironment \alert{IDE}.
    \end{itemize}
    \item Install the following applications by downloading them from the Web.
    \begin{itemize}
      \item \alert{\texttt{SmartGit}} a free (for non-commercial use) versatile frontend for git. (See: \alert{\href{https://www.syntevo.com/}{https://www.syntevo.com/}})
    \end{itemize}
  \end{itemize}
\end{frame}
