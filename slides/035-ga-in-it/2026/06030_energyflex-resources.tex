\begin{frame}{EnergyFlex -- Prototype Scope \& Required Resources}
\small
\begin{columns}[T,onlytextwidth]
    \begin{column}{0.52\textwidth}
        \textbf{Hardware}
        \begin{itemize}
            \item ESP32-class control/measurement nodes with LoRaWAN
            \item Representative low-voltage loads: pump, fan, lamp, charger or heater
            \item Voltage/current/power measurement
            \item MOSFET, relay or suitable low-voltage solid-state switching
            \item Optional process sensors such as temperature or water level
            \item Optional thermal-storage demonstrator with insulated water container, 12/24\,V heater and temperature sensor
        \end{itemize}
    \end{column}
    \begin{column}{0.48\textwidth}
        \textbf{Software \& Infrastructure}
        \begin{itemize}
            \item LoRaWAN gateway and The Things Network
            \item MQTT / MQTTSuite backend
            \item Database for measurements and decisions
            \item Renewable-aware control logic
            \item Web dashboard
        \end{itemize}
    \end{column}
\end{columns}

Flexible loads automatically move into periods of renewable-energy surplus while critical loads remain available.
