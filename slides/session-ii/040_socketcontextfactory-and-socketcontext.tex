\section[nosectionpage]{The \texttt{SocketContextFactory} and the \texttt{SocketContext} of the MQTT-Broker}

\begin{frame}[fragile]{The \texttt{SocketContextFactory} and the \texttt{SocketContext} of the MQTT-Broker}
  \begin{itemize}
    \item \textcolor{fh-ooe-red}{MQTT-Broker}'s \textcolor{fh-ooe-red}{\texttt{SocketContextFactory}} itself is designed as a \textcolor{fh-ooe-red}{template class} expecting a \textcolor{fh-ooe-red}{\texttt{std::string}} as \textcolor{fh-ooe-red}{non-type template argument} which has to contain a \textcolor{fh-ooe-red}{JSON} object.
    \begin{itemize}
      \item By \textcolor{fh-ooe-red}{providing} such a \textcolor{fh-ooe-red}{JSON} object the \textcolor{fh-ooe-red}{broker} would \textcolor{fh-ooe-red}{also} act as an \textcolor{fh-ooe-red}{integrator} which \textcolor{fh-ooe-red}{maps incoming topics and messages} to \textcolor{fh-ooe-red}{outgoing topics and messages controlled} by the \textcolor{fh-ooe-red}{mapping describtion in the JSON} object.
      \item If \textcolor{fh-ooe-red}{no JSON}-mapping (empty string) is provided, the broker acts as a \textcolor{fh-ooe-red}{pure broker}.
    \end{itemize}
    \item \textcolor{fh-ooe-red}{MQTT-Broker}'s \textcolor{fh-ooe-red}{\texttt{SocketContext}} is a class which \textcolor{fh-ooe-red}{inherits multible super classes}. Most \textcolor{fh-ooe-red}{important} it is \textcolor{fh-ooe-red}{derived from} the plain \textcolor{fh-ooe-red}{\texttt{iot::mqtt::server::SocketContext}} provided by SNode.C.
    \begin{itemize}
      \item The \textcolor{fh-ooe-red}{\texttt{iot::mqtt::server::SocketContext} already provides a full MQTT broker} implementation.
      \item By \textcolor{fh-ooe-red}{inheriting from this class} one has the \textcolor{fh-ooe-red}{opportunity} to \textcolor{fh-ooe-red}{override any method associated with incoming MQTT packets}, most \textcolor{fh-ooe-red}{important} the \textcolor{fh-ooe-red}{\texttt{onPublish}} method, \textcolor{fh-ooe-red}{associated} with an incoming \textcolor{fh-ooe-red}{MQTT publish packets}.

      \begin{cppcode}[gobble=8]
        void onPublish(iot::mqtt::packets::Publish& publish) override;
      \end{cppcode}
      \item This \textcolor{fh-ooe-red}{method is called for every incoming MQTT publish message}.
      \item The \textcolor{fh-ooe-red}{\texttt{iot::mqtt::packets::Publish}} argument passed to ths method \textcolor{fh-ooe-red}{contains the complete information of the publish message}.
    \end{itemize}
  \end{itemize}
\end{frame}
