\subsection{The JSON Structure of a \texttt{value} Mapping Section}

\begin{frame}[fragile]{The JSON Structure of a \texttt{value} Mapping Section}
  The \textcolor{fh-ooe-red}{\texttt{value}} mapping section describes the \textcolor{fh-ooe-red}{mapped topic} and the \textcolor{fh-ooe-red}{message mapping} where the \textcolor{fh-ooe-red}{incoming message} is \textcolor{fh-ooe-red}{interpreted as value} of an \textcolor{fh-ooe-red}{\href{https://github.com/pantor/inja/tree/master}{inja template}}. The \textcolor{fh-ooe-red}{value} is available in the template in the variable \texttt{\textcolor{fh-ooe-red}{value}}\\E.g.:

  \begin{jsoncode}[gobble=4]
    "value" : {
        "mapped_topic" : "test02/onboard/set",
        "retain_message" : false,
        "mapping_template" : "{% if value == \"pressed\" %}on{% else if value == \"released\" %}off{% endif %}"
    }
  \end{jsoncode}
  Have a look at the \textcolor{fh-ooe-red}{\href{https://github.com/pantor/inja/tree/master}{inja documentation}} for more details about templates.
\end{frame}
